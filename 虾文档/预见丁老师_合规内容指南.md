## 二、内容包装策略

### 2.1 三大包装方向

```
方向1：【传统文化派】
├─ 包装：国学智慧 / 易学文化 / 东方哲学
├─ 表达：用"易学"替代"算命"，强调文化传承
└─ 示例："今天分享一个易学中的能量规律"

方向2：【数据分析派】
├─ 包装：人生算法 / 生命数据 / 规律分析
├─ 表达：用"数据分析"替代"算命"
└─ 示例："根据你提供的能量信息，帮你分析一下"

方向3：【心理辅导派】
├─ 包装：情感咨询 / 决策顾问 / 人生规划
├─ 表达：结合心理学，更容易被平台接受
└─ 示例："从能量角度给你一些人生建议"
```

### 2.2 内容形式合规化

```
❌ 原形式：
"我用奇门帮你算算你今年的感情运势"

✅ 合规形式（选其一）：

A. 传统文化派：
"用易学智慧，帮你分析2024年的情感发展趋势"

B. 数据分析派：
"你的能量状态显示，今年感情方面要注意这3点"

C. 实用干货派：
"从环境能量学角度，帮你分析卧室布置对感情的影响"

D. 心理学派：
"心理学+能量规律，帮你看清感情中的这些问题"
```

## 七、合规内容红线清单

### ⚠️ 绝对不能出现的词

```
🚫 命 / 算命 / 看命
🚫 运势（可替换为：发展趋势、能量状态）
🚫 算卦 / 起卦
🚫 神仙 / 鬼怪 / 妖魔
🚫 化解（改为：优化、调整）
🚫 驱邪 / 辟邪
🚫 改命 / 改运
🚫 神仙保佑 / 菩萨保佑
🚫 迷信
```

### ⚠️ 避免过度承诺

```
🚫 "一定准" / "保证准"
🚫 "100%命中"
🚫 "不准不要钱"（暗示不精准）
✅ 改为："规律分析供参考"
✅ 改为："准确率因人而异"
✅ 改为："希望对你有帮助"
```

### ⚠️ 避免恐吓式表达

```
🚫 "如果你不化解，会..."
🚫 "不这样做，你会倒霉"
🚫 "命中注定要离婚"
✅ 改为："从能量角度，建议关注..."
✅ 改为："如果优化一下，能量状态会更好"
✅ 改为："从规律看，这是一个需要特别注意的点"
```

## 八、平台审核应对策略

### 8.1 标题党式包装

```
❌ 直接型："算算你今年能不能发财"
✅ 包装型："能量规律显示，今年这3类人发展机会大"

❌ 直接型："奇门遁甲算命教学"
✅ 包装型："易学智慧入门：能量分析的基本原理"

❌ 直接型："婚姻宫看离婚"
✅ 包装型："关系能量学：什么信号说明关系需要调整"
```

### 8.2 内容结构优化

```
原结构（容易被判定）：
1. 开门见山讲"命理"
2. 直接给"预测结果"
3. 用"大师"口吻

合规结构：
1. 先讲现象/问题（引发共鸣）
2. 引入"能量/规律/智慧"概念
3. 用"分析"口吻（非权威判定）
4. 给"建议/方向"（非绝对结果）
```

### 8.3 评论区引导话术

```
❌ "想算的私信"
✅ "想了解能量规律的可以私信"

❌ "把你的八字发来"
✅ "方便的话说一下你的生日时间"

❌ "准不准？"（可能引发举报）
✅ "有帮助的话点个赞"
```

## 九、合规检查清单

每次发布内容前，检查以下项目：

```
□ 标题是否包含敏感词？
□ 封面文字是否合规？
□ 视频/音频是否提到敏感词？
□ 简介/评论引导是否合规？
□ 是否过度承诺结果？
□ 是否使用恐吓式表达？
□ 是否有迷信化包装？
```
